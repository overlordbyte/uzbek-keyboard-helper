## Tugmalar

| Tugma kombinatsiyasi | Natija |
|---|---|
| `Right Alt` + `S` | `ş` |
| `Right Alt` + `Shift` + `S` | `Ş` |
| `Right Alt` + `O` | `ö` |
| `Right Alt` + `Shift` + `O` | `Ö` |
| `Right Alt` + `G` | `ğ` |
| `Right Alt` + `Shift` + `G` | `Ğ` |
| `Right Alt` + `C` | `ç` |
| `Right Alt` + `Shift` + `C` | `Ç` |

> **Eslatma:** Faqat **o'ng Alt** ishlaydi. Chap Alt (masalan, `Alt+F4`) odatiy tarzda ishlayveradi.

---

## O'rnatish

1. Yuqoridagi **Yuklab olish** tugmasini bosing
2. `UzbekKeyboardHelper.exe` faylini qulay joyga saqlang
3. Dasturni ishga tushiring — tizim tepsisida O'zbekiston bayrog'i ko'rinadi
4. Dastur avtomatik ravishda kompyuter yonganda ishga tushish uchun ro'yxatdan o'tadi

## Xususiyatlar

- Tizim tepsisida O'zbekiston bayrog'i ko'rinadi

- Yoqish / o'chirish imkoniyati
- Qo'shimcha o'rnatuvchi dastur kerak emas — bitta `.exe` fayl
